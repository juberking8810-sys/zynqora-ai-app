🚀 Android Studio & Google Play Store Instructions

  1. Click the Download Full Project ZIP button above and extract the downloaded file.
  2. Open Android Studio and select Open, then choose the extracted /android folder.
  3. Android Studio will sync the Gradle project automatically.
  4. To test on your device or emulator, press Run 'app' (Shift + F10).
  5. To build a Google Play release bundle, go to Build > Generate Signed Bundle / APK and choose Android App Bundle (.aab), or run cd android && ./gradlew bundleRelease in terminal.
